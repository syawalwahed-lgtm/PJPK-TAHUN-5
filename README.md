## GitHub Pages
1. Cipta repo baharu, contoh `pjpk-tahun5-interaktif`.
2. Upload `index.html`.
3. Settings → Pages → Deploy from a branch → `main` → `/root` → Save.
4. URL lazim: `https://USERNAME.github.io/pjpk-tahun5-interaktif/`.
5. QR dalam laman akan menjana berdasarkan URL GitHub Pages.
